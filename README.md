# Project Digital Sentry: AI-Powered Deepfake Detector

A 4-year high school research project dedicated to identifying synthetic media. This system is designed to analyze both pre-recorded files and live video streams to catch modern deepfake scams.

## 4-Year Development Pipeline
* **Year 1:** Analyze video/audio synchronization flaws and stream structural properties.
* **Year 2:** Implement machine learning classifiers to analyze frame-by-frame pixel boundaries.
* **Year 3:** Build real-time streaming data interceptors (detecting virtual camera injections).
* **Year 4:** Create a unified web dashboard for live call protection.

## Current Project Structure
* `src/analyzer.py` - Core Python script evaluating media data integrity.
* `data/` - Placeholder for future open-source deepfake sample files.
